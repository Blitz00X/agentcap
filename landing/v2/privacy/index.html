Privacy

Last updated 24 November 2026. This page covers the agentcap CLI (PyPI agentcap-cli), the AgentCap Claude Code plugin, the AgentCap Codex plugin and this website. AgentCap is made by Kutay Karahan (Launchbench). Contact: kutaykarahan6@gmail.com.

The short version

  • AgentCap runs on your machine. It has no account, no analytics and no telemetry.
  • It never stores or uploads prompts, responses, tool inputs, tool output, API keys or OAuth tokens.
  • Free makes no network requests of its own. Pro contacts only Polar, to check your licence key.

What stays on your machine

  • Claude Code and Codex plugins (~/.local/state/agentcap/quota/): session ids, quota percentages and reset times, counters, tool names, a 16-character hash of each tool call, and stop receipts (numbers and the last tool name). Loop counters are deleted after 7 days, session files after 30 days, receipts after 90 days.
  • /agentcap:setup sets the statusLine key in ~/.claude/settings.json and keeps an owner-only backup of that file until /agentcap:unsetup deletes it.
  • CLI: a local ledger (~/.local/share/agentcap/) with token counts, costs, model names, timestamps and request hashes; agentcap import reads your local Claude Code and Codex session logs and stores only usage numbers from them. Prompts and API keys pass through the local proxy in memory and are never written to disk.

You can delete all of it at any time by removing those folders.

What leaves your machine

  • Pro licence checks. Activating a Pro key, and a re-check about once a week, sends the licence key, the Polar organization id and an anonymous machine fingerprint hash (SHA-256, no hostname or username) to Polar's licence API (api.polar.sh). The plugins never make this request; only the CLI does. Free users make no licence requests.
  • Alerts you configure (Pro). If you set a Telegram bot or a webhook, AgentCap sends alert metadata to it: run id, spend or quota %, stop reason. Nothing is sent unless you set these up.
  • Your agent's own traffic. With an API key, agentcap run forwards your agent's requests to the provider you use (Anthropic, OpenAI, Google) unchanged except for the output limit. Subscription logins are never proxied.

Buying Pro

Checkout, payment and the licence key are handled by Polar, our merchant of record. Polar receives your email address and payment details under its own privacy policy. We receive your email address and order from Polar to deliver the key and to handle refunds and support.

This website

No cookies, no trackers, no analytics, self-hosted fonts. Like any web server, ours may keep standard access logs (IP address, time, requested page) for security and operations.

Children

AgentCap is a developer tool and is not directed at people under 18.
