          Honest limits: can a subscription quota stop overshoot slightly?
          
Yes — by up to one in-flight model response, because Claude and Codex report subscription % once per response and account-wide. In a live 2% test on Claude Pro, one reply landed mid-check and stopped at 4%. The 4× loop breaker stops deterministically before the 4th tool call runs.

        

        

          How does AgentCap compare to LoopGuard or RelayPlane?
          
RelayPlane is a great API proxy (no subscription quota). LoopGuard charges $9/month for paid controls. AgentCap combines free local waste forensics (agentcap waste), native in-session /agentcap commands, and a $7 one-time Pro licence.
